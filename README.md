# ZIGSO · 한 조각의 여유

**플레이: https://bluehige.github.io/zigso/**

사용자가 제공한 세로 일러스트 10장으로 만든 모바일 직소 퍼즐입니다. 설치, 로그인, 광고, 외부 API 없이 정적 웹사이트에서 동작합니다.

## 게임

| 난이도 | 조각 수 | 격자 |
|---|---:|---|
| 초급 | 12 | 3 × 4 |
| 중급 | 24 | 4 × 6 |
| 고급 | 54 | 6 × 9 |

실제 요철 모양의 조각을 퍼즐판으로 끌어놓거나 **조각 선택 → 맞는 빈칸 터치**로 배치합니다. 가까운 정답 위치에는 자동으로 맞춰집니다. 조각 회전과 시간 제한은 없습니다.

한 장면을 완성하면 다음 장면이 열립니다. 어느 난이도로 클리어하든 스테이지 해금은 공유하며, 각 난이도의 진행과 최고 완료 시간은 별도로 저장합니다. 마지막 장면 이후에는 컬렉션으로 돌아가 재도전할 수 있습니다.

원본 보기, 밑그림 토글, 정답 위치를 잠시 표시하는 무료 힌트, 테두리 조각 필터, 조각 섞기, 1.75배 확대와 터치 스크롤, 효과음 설정을 제공합니다. 미리보기와 메뉴를 여는 동안 타이머는 정지합니다. 다시 시작은 현재 퍼즐만 초기화하며, 완료 기록과 해금은 유지합니다.

## 이미지 처리

저장소의 `동급생.zip`을 그대로 사용합니다. 브라우저에서 ZIP 목록을 읽고 압축 해제와 CRC32 무결성 검증을 거쳐 이미지 10장을 연결합니다. 별도 이미지 업로드 서비스나 CDN에 재전송하지 않습니다.

원본 파일은 `01, 02, 03, 05, 06, 07, 08, 09, 10, 11.jpg`입니다. 원본에 `04.jpg`가 없는 상태를 그대로 존중하고, 실제 게임에서는 순서대로 스테이지 01~10으로 표시합니다. 퍼즐판에는 **1080 × 1600 원본**을 잘라내지 않고 사용합니다. 컬렉션 썸네일은 실행 시 별도로 생성합니다.

첫 실행에는 약 8.6MB의 ZIP 다운로드가 필요합니다. 이미지 팩은 지원되는 브라우저의 Cache Storage에 보관되어 재방문 시 재사용됩니다. 완전한 오프라인 앱은 아니므로 사이트를 처음 열 때는 인터넷 연결이 필요합니다.

최신 Chrome, Samsung Internet, Safari, Firefox를 대상으로 합니다. ZIP 해제에는 브라우저의 `DecompressionStream('deflate-raw')`가 필요하며, 미지원 브라우저에는 업데이트 안내를 표시합니다.

## 저장과 개인정보

진행 정보는 `localStorage`의 `zigso-save-v1`에 저장합니다. 기기 및 브라우저 간 동기화는 없습니다. 시크릿 모드나 저장 공간 부족으로 저장에 실패하면 안내를 표시합니다. 브라우저 데이터를 삭제하면 진행이 지워질 수 있습니다. 사용 통계, 광고 SDK, 계정, 외부 수집 서버는 없습니다.

## 파일

- `index.html`, `style.css`: 세로 UI와 반응형 레이아웃
- `app.js`: 입력, 스테이지, 저장, 타이머, 모달, 캔버스 렌더링
- `puzzle.js`: 결정적 조각 생성과 맞물리는 가장자리
- `assets.js`: 사용자 ZIP 해제, 검증, 썸네일 생성
- `tests/geometry.test.mjs`: 조각 수, 경계 상보성, 셔플 테스트
- `tests/browser_smoke.py`: 배포 사이트의 모바일 브라우저 통합 테스트
- `docs/UX-REFERENCES.md`: 참고 서비스와 채택·제외한 기능

## 로컬 실행

```sh
python -m http.server 8080
# 브라우저에서 http://localhost:8080 열기
npm test
```

런타임 패키지 설치나 빌드 과정은 없습니다. `file://`로 HTML을 직접 열면 이미지 팩을 fetch할 수 없으므로 HTTP 서버를 사용하세요.

## 배포

`gh-pages` 브랜치 루트를 GitHub Pages가 게시합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 원본과 코드는 `main`에도 보관합니다. 두 브랜치를 변경할 때는 검증한 커밋을 `gh-pages`로 fast-forward해야 합니다.

`gh-pages` 변경 시 검증 워크플로가 공개 URL을 열어 실제 ZIP 로딩, 터치 조작, 저장 복원, 난이도, 10개 스테이지 진행을 확인하고 스크린샷을 아티팩트로 남깁니다. 테스트 결과는 Actions 로그에서 확인할 수 있습니다.

## 이미지 권리

이미지는 사용자가 제공한 자료입니다. 이미지에 대한 별도 재배포 라이선스는 부여하지 않습니다.
