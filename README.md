# ZIGSO · 조각의 시간

모바일 세로형 직소 퍼즐 웹게임.

## 제작 범위

- 제공된 세로 일러스트 10장, 순차 스테이지 해금
- 초급 12조각 / 중급 24조각 / 고급 54조각
- 실제 요철 모양 직소 조각, 드래그 및 탭 배치
- 테두리 필터, 확대, 원본 미리보기, 힌트
- 기기 내 진행 자동 저장
- 정적 웹 배포, 서버 및 로그인 불필요

현재 초기 구현 중입니다. 실행 파일과 테스트 결과는 후속 커밋에 추가합니다.

## 이미지

사용자가 제공한 이미지입니다. 이미지에 대한 별도 재배포 라이선스는 부여하지 않습니다.
